# Greed Island (Roblox + Rojo) — полный контекст проекта

Этот файл читает Claude Code при запуске в этой папке. Он написан, чтобы новая сессия сразу поняла игру, не перечитывая историю.

## Что это

Игра по мотивам «Острова Жадности» из Hunter × Hunter. Игрок входит в игру через консоль JoyStation, собирает 100 карт в книгу (переплёт), покупает заклинания, ловит монстров, выполняет задания, проходит финальную викторину и выходит через башню Елены. Весь остров (ландшафт, города, NPC, монстры, интерфейс) строится кодом — ассеты из Toolbox не используются. Весь текст в игре — на русском.

- Репозиторий: `github.com/asilJPG/rb-hassle`. Игра — в ветке **`greed-island`** (49+ коммитов поверх `main`). В `main` осталась прежняя игра про вождение (коммит `b0779a7`, трафик-ИИ, A-Chassis): ей эта работа не мешает. Ветка **не запушена**; пушить и сливать с `main` только по просьбе пользователя.
- Источник правил — скриншоты вики в `docs/reference/` (13 файлов: описание, кольцо, переплёт, части карты и ранги, валюта, локации, создатели, NPC, бестиарий, монстры).
- Состояние: код собирается (`rojo build`), анализатор Luau чист, тесты на заглушках проходят. **В Roblox Studio игру ни разу не запускали** (в сессиях, где её писали, Studio не было). Пользователь запускал её сам и сообщил: «все есть, но персонажа нет» и «NPC не двигаются» — после этого добавлена ходьба NPC и страховка загрузки персонажа, но подтверждения от пользователя ещё нет.

## Запуск и проверка

```bash
rojo serve                       # Studio: плагин Rojo -> Connect (плагин нужен только этот)
rojo build -o game.rbxl          # проверка сборки без Studio
node tools/check/build.js        # данные и логика книги на заглушках (нужен luau; LUAU=путь\к\luau.exe)
```

- Rojo 7.7.1 (`aftman.toml`). Если Aftman не установлен: exe с `github.com/rojo-rbx/rojo/releases` и `rojo plugin install`.
- Анализатор: `luau-analyze --formatter=plain <файл>` (релизы `github.com/luau-lang/luau`). Типы Roblox ему неизвестны, поэтому строки `Unknown type`, `UnknownGlobal`, `UnknownType`, `Unknown global` игнорируются; смотреть на остальное (синтаксис, неиспользуемые переменные, ошибки логики).
- `tools/check/build.js` встраивает `src/` в один Luau-файл (в интерпретаторе нет `io` и Roblox API) и прогоняет:
  - `data_check`: ровно 100 карт, 32 заклинания, ссылки на зоны, монстров и лавки целы, распределение рангов;
  - `logic_check`: рука, слоты, лимиты рангов, «Получить», 45 свободных слотов, round-trip профиля, выход игрока во время загрузки, сбой DataStore (старое сохранение не затирается).
- Для сохранения прогресса в Studio включите *Game Settings → Security → Enable Studio Access to API Services*; без этого игра работает, но книга не сохраняется (в Output предупреждение).

## Механики и принятые решения

- **Книга:** 100 указанных слотов + 45 свободных (дубликаты, заклинания, еда). Карта из рук не вкладывается — место ей находит `Binder.insert`: свой слот, иначе свободный.
- **Рука:** подобранный предмет становится картой в руке (до 6). За 60 секунд её надо вложить, иначе `Hand` возвращает предмет в мир и освобождает копию. При смерти рука пропадает (заклинание «Воскрешение» её спасает).
- **Лимиты рангов:** копий одной карты на сервере не больше `Ranks.limit`; пока лимит выбран, предмет не превращается в карту. «Вернуть в исходное» освобождает копию. «Получить» копию НЕ освобождает (предмет израсходован навсегда).
- **«Получить»:** заклинание срабатывает, еда лечит, «10 000 йен» (теперь ранг C, лимит 20) пополняет кошелёк, «Меч Истины» удваивает урон навсегда. Благословение правителя использовать нельзя.
- **Йены:** хранятся числом в профиле и показываются как карта «Кошелёк» (1 карта = виртуальная, в слот не кладётся).
- **Источники карт:** предметы в мире (по рангу 1–4 узла на карту), монстры, лавки (B-карты — после 50 покупок в одной лавке), задания, казино (карты 29–32 только отсюда), конкурс (рыба Галгайда), финальная викторина (Благословение правителя).
- **Добыча с монстров:** делится по вкладу в урон (`MonsterService.distribute`): йены пропорционально доле, последний удар даёт +10% к доле (`Config.LastHitBonus`). Шанс карты = доля × (участников + 1) / 2 (соло 100%), если никому не выпало — карта у самого сильного. Приёмы-поимки (удар в слабое место, Зетсу→Тен, серия по дереву) засчитываются как полный вклад. В открытом мире вклад меньше 10% не награждается. Карта идёт в руку, при полных руках — сразу в книгу.
- **Арены боссов:** Король жук-олень, Альфа-волк и Меланиновая ящерица (`arena` в `Monsters.luau`) в открытом мире не появляются. Портал в Лесу/Топях открывает меню: соло, группа друзей (создаёт и запускает хозяин, до 4) или очередь на дуо/трио/квартет (45 с ожидания, потом старт с теми, кто есть, если двое и больше). У каждой группы своя площадка (6 на босса), HP босса растёт с размером группы (`ArenaHpScale`), на бой 5 минут, выйти можно только сдавшись. Заклинания телепорта в бою отключены. Босс недоступен, пока копии его карты исчерпаны. Всё не проверено в Studio.
- **Карты с эффектом и без:** что делает «Получить», описывает `shared/CardUse.luau` (еда, зелья, йены, особые предметы, заклинания); описание показывается на самой карте. У коллекционных карт (горшок и т. п.) эффекта нет, «Получить» их не тратит. Заклинание «Полёт» одно: при использовании игрок выбирает город (`SpellChoice`/`SpellChoose`), карта тратится только после выбора.
- **Гардероб героев:** NPC в Антокибе продаёт образы (`shared/Skins.luau`, `SkinService`) за йены; образ — косметика, хранится в `profile.outfit`, купленные — флаги `skin_<id>`.
- **Победа:** все 100 слотов (последняя карта — Благословение у Двана в Лимейро). Выход — Елена с «Транспортным билетом» или заклинание «Покинуть». Победителю достаётся футляр на 3 слота (три самые редкие карты, считаются при выходе).
- **Монстры:** Циклоп (удар в глаз), Пузырьковая лошадь (Зетсу, затем Тен рядом), Радиокрыса (падает в обморок), Король жук-олень (4 удара по дереву за 2.5 с), Меланиновая ящерица (родинка ×8), Гипердождевик (быстрый), стая Альфа-волка, три безымянных (одноглазый, слизь, червь).
- **Экономика (оценка на бумаге):** до победы нужно порядка 180 тыс. йен (покупки ~130 тыс., заклинания, билет, лекарства). Цены продажи по рангам низкие (SS 8000 … H 30, лавка платит 0.4), предметы возрождаются через 75 с, казино с матожиданием около −5%. Фарм «подобрал-продал» закрыт.
- **Безопасность сервера:** все Remote-обработчики проверяют типы, `inGame` и расстояние до NPC/лавки; есть ограничения частоты (sync книги 0.5 с, действия в лавке 0.15 с). Клиентам нельзя доверять числа — сервер сам считает цены, лимиты и урон.
- **Запуск устойчив к ошибкам:** `Main.server` оборачивает каждый сервис в pcall (ошибка в одном не лишает игрока персонажа). `StreamingEnabled` выключен в `default.project.json`.
- **Лобби:** «реальный мир» — комната на `RealWorldPos` (0, 1500, 0). Игрок появляется там (`RespawnLocation = lobbySpawn`), заходит в игру через ProximityPrompt на JoyStation.
- **Состояние клиента:** сервер шлёт полный снимок (`State`) при каждом изменении; клиентские таймеры (рука, эффекты) тикают локально по `receivedAt`.

## Известные слабые места и что проверить в Studio

1. **Персонаж не появляется** (жалоба пользователя) — причина по коду не найдена. Цепочка: `GameService.onPlayerAdded` выставляет `RespawnLocation = lobbySpawn`, при отсутствии персонажа через 3 с вызывается `LoadCharacter`. Проверить Output на красные строки и на `[Main] <сервис>: ...`; убедиться, что в `Workspace` нет старых скриптов и что `Players.CharacterAutoLoads` включён.
2. **NPC и монстры двигаются** — написано (`NpcService.animate`, `MonsterService`), но не подтверждено в Studio. Монстры замечают только игроков, которые уже вошли в игру (`profile.inGame`).
3. **Раскладка на телефоне:** кнопки `TouchControls` над родной кнопкой прыжка, HUD с `UIScale`; не проверено на реальных устройствах.
4. **Мир:** тропы покрашены по сетке в 4 студа (могут быть ступенчатыми); положение указателей, фонарей, заборов, лодок относительно рельефа и воды; производительность клиента (`Ambient`, сотни деталей).
5. **Баланс боя, казино и прохождения** считался на бумаге.
6. README ещё называет «10 000 йен» без ранга и описывает распределение рангов 3/5/8/12/15/15/14/12/10/6 — фактически сейчас C=16, F=11 (карта «10 000 йен» теперь ранга C).

## Правила работы в этом репозитории

- Работать в ветке `greed-island`. Не пушить и не трогать `main` без прямой просьбы. Не удалять `docs/reference`.
- Коммиты — короткие, по-русски, **без строки Co-Authored-By**.
- Весь пользовательский текст в игре — на русском; числа игры — только в `src/shared/Config.luau`, новая карта — одна строка в `Cards.luau`.
- Перед переименованием функций — `grep` по `src/`: модули часто вызывают друг друга лениво (`require` внутри функции, чтобы не было циклов).
- Каждая правка: анализатор Luau → `rojo build` → при изменении данных/логики `node tools/check/build.js`.
- Не писать длинный Luau через bash-heredoc с кавычками (ломается): использовать файл или Node-скрипт; переносы строк в Luau-строках вставлять осторожно.
- Не добавлять внешних зависимостей и ассетов из Toolbox.
