# Greed Island (Roblox + Rojo)

Игра по мотивам «Острова Жадности» из Hunter × Hunter: вы входите в игру через консоль, собираете 100 карт в книгу
и выходите победителем. Весь остров (ландшафт, города, NPC, монстры, интерфейс) строится кодом — ничего
не нужно собирать вручную в Studio и нигде не нужны ассеты из Toolbox.

Референсы (скриншоты вики) лежат в `docs/reference/`.

## Запуск

```bash
aftman install      # поставит Rojo 7.7.1 (или установите Rojo сами)
rojo serve
```

В Studio: плагин **Rojo** → Connect. Плагин нужен один — он синхронизирует код. Больше ничего ставить не требуется.

Чтобы работало сохранение прогресса, включите в Studio *Game Settings → Security → Enable Studio Access to API Services*.
Без этого игра работает, но книга не сохраняется между запусками (в консоли будет предупреждение).

Проверка сборки без Studio: `rojo build -o game.rbxl`.

## Как играть

| Клавиша | Действие |
|---|---|
| E | подобрать предмет, поговорить с NPC, войти через JoyStation |
| B | открыть книгу |
| G | режим «Приращение» (карта становится настоящей вещью) |
| T / Z | Тен (меньше урона) / Зетсу (монстры почти не замечают) |
| ЛКМ / тап | удар «Нен» по монстру |
| / | строка слов кольца: «Книга», «Приращение», «Тен», «Зетсу» |
| Esc | закрыть диалог или лавку |

1. Появляетесь в «реальном мире». Подойдите к **JoyStation** (E) — вы на острове у Дерева Шисо.
2. **Эта** (гейм-мастер входа) объяснит правила и выдаст стартовые карты.
3. Подбирайте предметы, побеждайте монстров, покупайте и выполняйте задания. Предмет превращается в карту в руке —
   **за минуту** её надо вложить в книгу, иначе она снова станет предметом.
4. Заполните все 100 слотов. Последняя карта — **Благословение правителя** (финальная викторина в Лимейро у Двана).
5. Выход — башня **Елены** (нужен «Транспортный билет») или заклинание «Покинуть». Победителю достаётся
   футляр на три слота с тремя самыми редкими картами.

## Механики (из вики)

- **Книга:** 100 указанных слотов + 45 свободных. Дубликаты, заклинания и еда — в свободных слотах.
- **Рука:** карта живёт в руке 60 секунд (`Config.HandSeconds`).
- **Ранги SS…H** (десять) и **лимит конвертации** на сервере: от 3 копий у SS до 120 у H (`Ranks.luau`).
  Пока лимит выбран, предмет в карту не превращается — ни у кого. «Вернуть в исходное состояние» освобождает копию.
  Израсходованная («Приращение») карта лимит не освобождает.
- **«Приращение»:** карта становится вещью, обратно в карту уже не вернётся. Заклинание срабатывает,
  еда лечит, «10 000 йен» пополняет кошелёк, «Меч Истины» удваивает урон навсегда.
- **Валюта:** йены есть только в виде карты «Кошелёк» (книга показывает баланс).
- **Четыре набора карт:** 100 особых, 40 заклинаний (`Spells.luau`, продаются только в Масадоре), карты свободных слотов,
  особые карты Дориаса — только из азартных игр.
- **Города и места** (`Zones.luau`): Дерево Шисо, Масадора, Суфраби, Аиай, Антокиба, Дориас, Рубикута, Лимейро, порт и башня Елены,
  Бесплодные земли, деревня горных бандитов, Бунзен, лес, топи, пещера, скалы, руины, луга, побережье.
- **Торговые лавки:** покупка, продажа (кроме заклинаний), «купить информацию»; карты ранга B продаются только после 50 покупок в одной лавке.
- **Магазин спелл-карт:** запас ограничен и пополняется, когда заклинания используют или игроки выходят.
- **Конкурс Антокибы** (раз в `ContestIntervalSeconds`): быстрый верный ответ у сцены — приз рыба Галгайда.
- **Дориас:** рулетка и дуэль с Королём казино — единственный источник карт 29–32.
- **Задания:** вылечить десять жителей горной деревни (карта «Лекарство») → Александрит «Дикая удача»;
  Девушка из золотой пыли (пройти мимо стража: заплатить, показать Меч Истины или сразиться);
  «Транспортный билет» у начальника порта (купить или выбить); участок на пляже; «Кошачья закусочная».
- **Монстры** (`Monsters.luau`): Циклоп (удар в глаз), Пузырьковая лошадь (Зетсу, затем Тен), Радиокрыса (падает в обморок),
  Король белый жук-олень (серия из четырёх ударов по дереву), Меланиновая ящерица (родинка на спине), Гипердождевик,
  волчья стая с Альфа-волком, три безымянных монстра.
- **Список игроков:** книга запоминает имена игроков, рядом с которыми вы постояли.
- **Смерть:** карты в руке пропадают (предметы возвращаются в мир), книга остаётся. Заклинание «Воскрешение» спасает руку.

## Структура

```
src/shared   данные и общие модули: Config, Ranks, Cards (100 карт), Spells (40), Monsters, Npcs, Zones, Quiz, Remotes
src/server   WorldBuilder (остров), ItemService, MonsterService, CombatService, NpcService, ShopService,
             QuizService, SpellService, Status, Hand, Binder(+Actions), CardRegistry, PlayerData, GameService
src/client   Main (ввод), Hud, BookUI, DialogUI, ShopUI, QuizUI, CardView, State, Theme
```

Все числа игры — в `src/shared/Config.luau`. Новая карта — одна строка в `Cards.luau`; источник задаётся
строкой (`p:Forest`, `m:Cyclops`, `s:antokiba:2500`, `q:...`, `c`, `k`, `x:...`).

## Что проверено без Studio

`rojo build` собирает проект, анализатор Luau не находит синтаксических ошибок, целостность данных проверена
скриптом (ровно 100 карт, распределение рангов 3/5/8/12/15/15/14/12/10/6, 40 заклинаний, все зоны и монстры существуют),
логика книги (рука → слот → дубликат → возврат → лимит ранга → «Приращение» → 45 свободных слотов) прогнана
на заглушках сервисов Roblox. Сам мир, ИИ монстров и интерфейс в Studio не запускались — первый прогон может
потребовать подстройки чисел и положений.
