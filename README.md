# Open-world driving (Roblox + Rojo)

Свободная езда по городу и шоссе. Физику машины даёт **A-Chassis**, остальное — код в `src/`.

## Запуск
```bash
rojo serve
```
В Studio: плагин Rojo → Connect.

## Что нужно собрать в Studio
```
Workspace            -- город/шоссе (карта, Toolbox), SpawnLocation для игроков
ServerStorage
└── Cars (Folder)
    ├── Sedan  (Model с VehicleSeat, настроенный под A-Chassis)
    └── ...
```
- Каждая машина = Model с `VehicleSeat`. A-Chassis ставится в Studio (Toolbox → "A-Chassis" /
  найдите актуальный открытый релиз), его машины кладите в `ServerStorage.Cars`.
- Если машина появляется боком или задом — поменяйте `CarYawOffsetDegrees` в `Config.luau` (90 / -90 / 180).
- Кнопки слева внизу спавнят машину перед игроком и сажают за руль. Спидометр справа внизу.
- Если у A-Chassis уже есть свой спидометр, его можно скрыть, удалив блок Speedometer в `Main.client.luau`.

## ИИ-трафик
Машины едут по полосам, которые вы рисуете вейпоинтами. Они сами тормозят перед препятствиями
(машины, игроки), углы сглаживаются. Перекрёстки не регулируются (см. ограничения).

```
Workspace
└── TrafficPaths (Folder)
    ├── Highway_East (Folder)   -- атрибуты: Loop (bool, по умолчанию true), SpeedLimit (studs/s)
    │   ├── 1  (Part)           -- вейпоинты по порядку движения, на поверхности дороги
    │   ├── 2
    │   └── ...
    └── Highway_West (Folder)
ServerStorage
└── TrafficCars (Folder, опционально)  -- Model'и для трафика; без них - простые коробки-машинки
```
- Каждая полоса движения = отдельная Folder. Для двусторонней дороги сделайте две папки,
  по одной на направление, с разным порядком точек.
- `Loop = true` — замкнутый круг. `Loop = false` — машина доезжает до конца и появляется в другом месте.
- Ставьте вейпоинты часто на поворотах, на прямых хватает точки каждые 50-100 studs.
- Шаблоны в `TrafficCars`: скрипты внутри удаляются, сиденья отключаются. Если шаблон едет боком —
  `Traffic.TemplateYawOffsetDegrees` в `Config.luau`.
- Количество машин, скорость, дистанции — в `Config.Traffic`.

**Ограничения:** на пересечениях полос машины не уступают друг другу (просто тормозят, а если
застряли на 20 секунд, их переставляют). Движение кинематическое: игрок не может сдвинуть
трафик столкновением. Для светофоров и приоритетов нужен следующий этап.

## «Шашки» (очки за близкие проезды)
Проезжаете мимо машины трафика ближе `Shashki.NearMissDistance` на скорости от `MinSpeedKmh` —
получаете очки. Подряд идущие проезды растят множитель (до x10), без нового проезда за 4 секунды
комбо сгорает, при аварии (потеря >40% скорости) тоже. Настройки — `Config.Shashki`.
Для плотного шоссе увеличьте `Traffic.Count` и сделайте несколько полос (по папке на полосу).
